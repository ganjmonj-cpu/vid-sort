# Vid Sort

A personal multi-source video curator starter page with a YouTube-inspired dark theme and responsive three-column results grid. Each sample card displays the source site, thumbnail, title, and creator.

## Preview

Open `index.html` in a browser, or deploy the repository as a static site with Cloudflare Pages.

## Current status

This is a frontend mockup with sample cards. Search, provider API connections, and blacklist filtering have not been implemented yet. Do not put API keys in the HTML or browser code; provider credentials should be stored as server-side Cloudflare secrets when backend search is added.
